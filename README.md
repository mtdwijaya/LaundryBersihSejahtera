# Laundry Bersih Sejahtera — Prototype

Prototype frontend Sistem Informasi Manajemen Laundry untuk presentasi/demo.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Data demo di `localStorage` (tanpa backend)

## Fitur

- Dashboard operasional
- Terima cucian + nomor nota unik
- Daftar & detail pesanan (update status + pembayaran)
- Master pelanggan
- Laporan harian/bulanan

## Menjalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Catatan

Inspirasi gaya UI dari [Chingu Laundry](https://chingu-laundry.com/) (teal, kuning, border tegas), diterapkan ke sistem kasir/operasional.
